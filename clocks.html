Server Clocks

Daily reset countdowns for all four servers, plus an estimated countdown to the next version update — everything shown converted to your own local time.

Daily Reset

Each server resets independently at 4:00 AM its own server time — Asia and TW/HK/MO happen to share a time zone, but all four are separate servers. The week strip below each clock marks the current in-game day.

Next Version Update

Unlike daily reset, a new version's maintenance starts at the same moment for every server at once — so this is a single estimate, not one per server.
